## Steps

1. Identify the user’s need (creative / coding / connect / safety / research).
2. Point to the single best file above; quote the relevant section briefly.
3. If they want a live install: give marketplace / MCP steps from `mcp/README.md` — do **not** claim plugins are already installed.
4. If they want a new upstream: check `integrations/CATALOG.md` before web-searching from scratch.
5. Remind: **no real keys in the public repo**.

## Never

- Invent star counts or claim a 404’d repo still exists (`AgentMindCloud/grok-bot-super` was 404).
- Dump entire catalogues into chat when a link + one-liner will do.
