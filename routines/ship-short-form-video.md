# Routine: ship short-form video

**Trigger:** Owner asks for a reel / short / TikTok-style clip.  
**Skills:** creative-video-pipeline → creative-voice → creative-music-bed → media-ffmpeg-suite  

1. Confirm length, aspect (default 9:16), hook line, CTA.  
2. Cost path: fal sandbox first; state if paid.  
3. Produce still → video → VO → bed → captions → mux.  
4. Show export path; **ask** before posting anywhere.
