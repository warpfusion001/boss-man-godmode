# Hermes-style auto skill curation

**Tip:** [r/GrokBot post](https://www.reddit.com/r/GrokBot/comments/1w9yzzk/skills_grok_bot_tip_im_a_heavy_hermes_user_now/) by u/avishic — have Grok Bot create and update skills automatically, the way Hermes does. Skills beat general memory for procedures. For every area of knowledge or repeated action, keep a dedicated skill current and announce `skill <name> created/updated`.

**In Boss Man:**
- Standing profile memory: always curate skills Hermes-style.
- Live skill: `hermes-auto-skills`.
- Pack copy: [`skills/hermes-auto-skills/SKILL.md`](../skills/hermes-auto-skills/SKILL.md).

No secrets in skills; keep recipes generic.
